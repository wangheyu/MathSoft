# 📝 Shell 编程实战作业：基于《War and Peace》

## 背景

你手头有一本英文小说《War and Peace》的纯文本文件，文件名为：

```
war_and_peace.txt
```

你的任务是使用 Shell 命令（如 `grep`, `awk`, `sed`, `cut`, `sort`, `uniq`, `wc` 等）
或脚本对该文本进行分析和处理，完成以下任务。


## 作业目标

掌握 Shell 编程中的文本处理技巧，包括：

- 字符串查找与计数
- 正则表达式
- 单词频率统计
- 行过滤
- 文件切分与重定向
- Shell 脚本逻辑控制

## 题目设计（共 8 题）


### **题目 1：统计行数、单词数与字符数**

**要求：**

使用 `wc` 命令统计 `war_and_peace.txt` 文件的：

- 总行数
- 单词数
- 字符数

**示例输出：**

```
Lines: 65677
Words: 567890
Characters: 3456789
```

### **题目 2：找出出现次数最多的前 10 个单词**

**要求：**

- 忽略大小写（将所有单词转为小写）
- 只统计字母单词（去除标点）
- 输出格式如下：

```
the     34567
and     28976
to      27890
...
```


### **题目 3：统计“war” 和 “peace” 出现的次数**

**要求：**

- 分别统计单词 "war" 和 "peace"（不区分大小写）在文本中出现了多少次
- 只匹配完整词，不匹配子串（如 "warm"）


### **题目 4：提取所有以 “Prince” 开头的行**

**要求：**

- 区分大小写
- 将所有以 "Prince" 开头的行提取到一个新文件 `prince_lines.txt`

### **题目 5：统计 BOOK 和 CHAPTER 的数量**

#### 要点：

- 区分：
  - `BOOK [A-Z]+` → 表示一本新书
  - `CHAPTER [A-Z]+` → 表示章节
- 输出格式：

```
Total Books: 15
Total Chapters: 365
```

**提示**：你需要用正则提取两种模式。

### **题目 6：提取 BOOK FIVE 中第一个章节的全部内容**

#### 要求：

- 提取从 `BOOK FIVE` 开始，到 `BOOK SIX` 之前的所有内容
- 保存为 `samples/book5.txt`

### **题目 7：找出包含“Napoleon”的行，并统计有多少行**

**要求：**

- 统计包含 “Napoleon”（区分大小写）的行数
- 并将这些行保存到 `napoleon_lines.txt`

### **题目 8（编程题）：写一个脚本 `summary.sh` 完成以下任务：**

- 接收一个关键词作为参数，例如：

```bash
./summary.sh pierre
```

- 输出：
  - 关键词在文本中出现的次数（不区分大小写）
  - 包含该关键词的前 5 行内容（可用 `grep -i`）
